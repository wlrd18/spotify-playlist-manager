Follow one click

A web app is a conversation between the page, the server, and the database. Learn that path and Codex's changes become much easier to read.

The dashboard load

Browser→/api/dashboard→FastAPI→SQLite→JSON back to browser

When the page opens, JavaScript in frontend/index.html calls fetch('/api/dashboard'). The route in backend/app/main.py reads the local SQLite database, returns JSON, and the page turns that data into cards and tables.

Why this helps when Codex changes something

  • A visual issue usually starts in frontend/index.html.
  • A wrong number or missing playlist often starts in an API route or analysis code.
  • Missing or stale data usually points to the Spotify sync or SQLite database.

Quick check

Which file first asks the server for dashboard data?

frontend/index.html. It runs in the browser and sends the request with fetch.

Try it now

Open frontend/index.html and find fetch('/api/dashboard'). Then open backend/app/main.py and find def dashboard(). You have just followed a full browser-to-database request.
