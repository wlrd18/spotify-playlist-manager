# Mission: Build and understand web apps

## Why
Use the playlist app to learn how real web apps work, so I can understand Codex's changes and gradually make safe changes myself.

## Success looks like
- Explain how a click in the dashboard reaches the backend and returns data.
- Read a small change from Codex and predict which files and behaviours it affects.
- Make, test, and verify a small feature without copying code blindly.

## Constraints
- Learn through this project in short, practical lessons.
- Prefer free tools and services.

## Out of scope
- Becoming a music-data specialist before understanding web-app basics.
